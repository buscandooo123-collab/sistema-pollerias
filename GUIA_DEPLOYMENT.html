🚀 Guía de Deployment

Sistema de Inventario de Pollerías - GitHub + Vercel

📦Archivos Listos:
Todo está en la carpeta poultry-apps-deploy con la estructura correcta.

📋 Estructura Final

sistema-pollerias/ ├── README.md ├── vercel.json ├── deploy.sh └── public/ ├── index.html (menú de inicio) ├── manifest.json ├── sw.js ├── madre/ │ └── index.html (App Madre) └── regreso/ └── index.html (App Regreso)

🔧 Opción 1: Usando el Script (Más Fácil)

1Descargar y Extraer

Descarga el ZIP poultry-apps-FINAL.zip y extráelo

2Abrir Terminal

Windows: Git Bash o PowerShell

Mac/Linux: Terminal

3Navegar a la Carpeta

cd ruta/donde/extrajiste/poultry-apps-deploy

4Ejecutar Script

bash deploy.sh
⚠️ Importante: Te pedirá tu usuario y contraseña de GitHub

📤 Opción 2: Subir Manualmente a GitHub

1Borrar Archivos Viejos

En GitHub, ve a tu repositorio y borra TODOS los archivos viejos

  • Selecciona cada archivo
  • Click en el icono de basura
  • Commit "Limpiar repositorio"

2Subir Archivos Nuevos

Click en "Add file" → "Upload files"

Arrastra TODA la carpeta poultry-apps-deploy

⚠️ Importante: Mantén la estructura de carpetas

3Commit

Escribe: "Sistema completo con estructura correcta"

Click en "Commit changes"

🚀 Desplegar en Vercel

1Ir a Vercel

Abre: https://vercel.com

Inicia sesión con GitHub

2Importar Proyecto

Click en "Add New" → "Project"

Busca: sistema-pollerias

Click en "Import"

3Configurar (MUY IMPORTANTE)

⚠️ CRÍTICO - No omitir:
  • Framework Preset: Other
  • Root Directory: public ← ¡IMPORTANTE!
  • Build Command: (dejar vacío)
  • Output Directory: (dejar vacío)

4Deploy

Click en "Deploy"

Espera 1-2 minutos...

✅¡Listo!
Tu app estará en: https://sistema-pollerias.vercel.app

📱 URLs Finales

  • Inicio: https://tu-proyecto.vercel.app/
  • App Madre: https://tu-proyecto.vercel.app/madre/
  • App Regreso: https://tu-proyecto.vercel.app/regreso/

  3. ¡Listo!

❓ Problemas Comunes

Error: "404 - File not found"
Solución: Verifica que pusiste public en "Root Directory"
Error: "Cannot find index.html"
Solución: La estructura de carpetas está incorrecta. Verifica que siga el formato mostrado arriba.
Los datos no se comparten entre apps
Solución: Asegúrate de que ambas apps estén en el mismo dominio:
tudominio.com/madre/ y tudominio.com/regreso/
